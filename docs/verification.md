# Проверка лабораторных 1–2

## Независимая реализация

Новые модули и интерфейс написаны по ТЗ в пустой рабочей папке. После реализации и первичных проверок выполнено сравнение поведения с опубликованной предыдущей версией https://photoshop-steelba11s.onrender.com/. Ссылка найдена в прежнем README. Исходники предыдущего приложения для реализации не использовались. Сторонний код в новой версии: только значки Lucide с лицензией; обработка пикселей собственная.

## Подтверждённые различия

Контрольные файлы создаются `tools/make-fixtures.mjs`. Старое приложение проверялось в отдельных новых вкладках, чтобы исключить остатки предыдущего документа.

| Проверка | Предыдущая версия | Новая версия |
| --- | --- | --- |
| PNG grayscale, 8 бит | R, G, B; глубина 8 бит | Gray; глубина 8 бит |
| PNG grayscale + alpha, 8 бит на компонент | R, G, B, A; глубина 32 бита | Gray, Alpha; глубина 16 бит |
| PNG RGB с серым содержимым | R, G, B | R, G, B |
| PNG RGBA, все пиксели непрозрачны | R, G, B, A | R, G, B, A |
| JPEG RGB | Глубина 24 бита | Глубина 24 бита |

Совпадение поведения в последних трёх строках подтверждает сохранение нужных свойств предыдущей версии. Различия в первых двух строках исправляют соответствие структуре каналов, требуемой лабораторной 2, и исходной глубине цвета из лабораторной 1.

Панель пипетки в новой версии постоянно находится рядом с каналами; флажки явно показывают включённые каналы. Добавлены загрузка перетаскиванием, собственная цветовая мишень, выбор точки с клавиатуры, сообщения о повреждённых файлах и сохранение предыдущего документа при ошибке загрузки. Это самостоятельные улучшения удобства, а не дополнительные требования лабораторных.

## Проверки

- Модульные: эталонные GB7, все 128 уровней серого, двоичная маска, RGB → Gray, повреждённые заголовки и данные, канальные комбинации, сохранность исходных пикселей, CIELAB на контрольных цветах, координаты, метаданные PNG/JPEG.
- Браузерные: загрузка и экспорт PNG/JPG/GB7; повторное открытие; прозрачность PNG; белый фон JPEG; бинарная маска GB7; независимое переключение каналов; все четыре модели каналов.
- Большие файлы: 3200×2400 для PNG, JPG и GB7; экспорт во все три формата; возврат управления браузеру при обработке; быстрые переключения каналов; пипетка при вписывании и после прокрутки в масштабе 1:1.
- Интерфейс: ширины 320, 390, 680, 900, 1440, 1920; отсутствие горизонтального переполнения страницы и текста в контролах; сохранение миниатюр на узком экране; закрытие экспорта через Escape; отсутствие необработанных ошибок JavaScript.

## Что ещё требуется для сдачи

Публикацию новой версии на хостинге нужно подтвердить и добавить ссылку на неё в README. Файлы из LMS недоступны в этой рабочей папке; их следует дополнительно прогнать через приложение перед сдачей. Проверки браузера выполнены в Chrome, а не во всех браузерах.
