# Пиксель

Самостоятельная реализация лабораторных работ 1 и 2 по обработке изображений. Интерфейс на HTML, CSS и JavaScript, без сборщика и UI-фреймворка. Алгоритмы работы с пикселями написаны в проекте; браузер используется для чтения и записи PNG/JPEG. Lucide используется только для значков интерфейса.

## Запуск

Нужен Node.js 20 или новее. Устанавливать зависимости не требуется.

```sh
node tools/serve.mjs
```

Адрес выводится в терминале; по умолчанию http://localhost:5173. Занятый порт пропускается. Открытие index.html через file:// не поддерживается из-за ES-модулей: нужен статический HTTP-сервер.

```sh
node --test tests/*.test.mjs
```

Для браузерных проверок нужен Playwright с Chrome. Запуск: `node tests/browser.mjs` при работающем локальном сервере. Если Playwright установлен отдельно, задайте `TEST_NODE_MODULES` (каталог node_modules); адрес сервера можно переопределить через `TEST_URL`. Playwright не является зависимостью самого приложения.

Тестовые файлы находятся в `samples/`: PNG всех четырёх моделей каналов, GB7 с маской и без неё, JPEG, а также изображения 3200×2400. Файлы PNG/GB7 воспроизводятся командой `node tools/make-fixtures.mjs`; JPEG создаются браузерными проверками. Файлы из LMS не предоставлены, поэтому вместо них используются собственные контрольные изображения.

## Лабораторная 1

- Загрузка PNG, JPG и GB7 через выбор файла или перетаскивание.
- Отрисовка на HTML canvas. Вписывание в рабочую область и просмотр 1:1 относятся только к отображению, исходные пиксели не изменяются.
- В нижней строке: исходные ширина, высота и глубина цвета, прочитанная из файла. Для JPEG с EXIF-поворотом размеры в строке остаются исходными, а координаты пипетки относятся к ориентированному изображению.
- Экспорт текущего вида в PNG, JPG и GB7. JPEG получает белый фон вместо прозрачности. PNG сохраняет прозрачность.
- GB7: собственные декодер и кодер, сетевой порядок байтов размеров, проверка сигнатуры, версии, резервных полей, размеров и точной длины данных.
- Ограничения памяти: 24 млн пикселей, 16 384 пикселя по стороне, 160 МБ на файл. Ошибка загрузки не удаляет открытый документ.

В ТЗ GB7 есть опечатка: после указания старшего бита маски дважды упоминается «бит 0». Здесь маска занимает **бит 7**, как указано в описании структуры пикселя; младшие 7 бит целиком отведены серому. При выключенном флаге маски старший бит должен быть нулём.

Серый при экспорте: `round((0.299 R + 0.587 G + 0.114 B) * 127 / 255)`. При чтении: `round(gray * 255 / 127)`. GB7 поддерживает только двоичную прозрачность: Alpha < 128 становится 0, Alpha >= 128 становится 255; наличие любого Alpha < 255 включает маску файла.

## Лабораторная 2

- Каналы Gray, Gray + Alpha, RGB, RGB + Alpha определяются метаданными формата, а не случайным содержимым изображения. PNG с палитрой разворачивается в RGB; tRNS добавляет Alpha. CMYK JPEG браузер преобразует в RGB, исходная глубина отмечена в статусе.
- Для каждого канала своя миниатюра интенсивности в оттенках серого и независимый флажок видимости.
- Выключенные цветовые компоненты обнуляются. Выключенный Alpha делает цвета непрозрачными. Только Alpha показывает непрозрачную серую маску: чёрный = прозрачный, белый = непрозрачный. Все выключенные каналы дают чёрное изображение.
- Пипетка считывает пиксель текущего вида canvas, без влияния шахматного фона и маркера. Координаты отсчитываются от нуля относительно изображения, включая режим вписывания и прокрутку. Показаны RGB 0–255, Alpha и CIELAB (sRGB, белая точка D65).
- Выбор через левую кнопку мыши; на сфокусированном canvas Enter выбирает центр, стрелки передвигают выбранную точку. Панель обновляется и при изменении каналов.
- Канальные преобразования выполняются порциями с передачей управления браузеру; устаревшие результаты быстрых переключений не отображаются.

## Структура

- `src/domain/`: пиксельные операции, цветовые пространства, каналы и собственная тестовая мишень.
- `src/io/`: GB7, метаданные PNG/JPEG, браузерное чтение и экспорт.
- `src/ui/`: стили и подключение значков.
- `src/main.js`: состояние документа и события интерфейса.
- `tests/`: проверки двоичного формата, каналов и численных преобразований.
- `vendor/lucide/`: выбранные значки Lucide и лицензия.

## Публикация

Публикация новой версии на хостинге пока не подтверждена. Для статического хостинга достаточно файлов проекта, сборка не нужна. Ссылку на новое развёртывание следует добавить сюда после проверки публикации; прежний сайт не считается развёртыванием этой реализации.
