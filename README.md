# Пиксель

Самостоятельная реализация лабораторных работ 1–5 по обработке изображений. Интерфейс на HTML, CSS и JavaScript, без сборщика и UI-фреймворка. Алгоритмы работы с пикселями написаны в проекте; браузер используется для чтения и записи PNG/JPEG. Lucide используется только для значков интерфейса.

## Запуск

Нужен Node.js 20 или новее. Устанавливать зависимости не требуется.

```sh
node tools/serve.mjs
```

Адрес выводится в терминале; по умолчанию http://localhost:5173. Занятый порт пропускается. Открытие index.html через file:// не поддерживается из-за ES-модулей: нужен статический HTTP-сервер.

## Лабораторная 1

- Загрузка PNG, JPG и GB7 через выбор файла или перетаскивание.
- Отрисовка на HTML canvas. Вписывание в рабочую область и просмотр 1:1 относятся только к отображению, исходные пиксели не изменяются.
- В нижней строке: исходные ширина, высота и глубина цвета, прочитанная из файла. Для JPEG с EXIF-поворотом размеры в строке остаются исходными, а координаты пипетки относятся к ориентированному изображению.
- Экспорт текущего вида в PNG, JPG и GB7. JPEG получает белый фон вместо прозрачности. PNG сохраняет прозрачность.
- GB7: собственные декодер и кодер, сетевой порядок байтов размеров, проверка сигнатуры, версии, резервных полей, размеров и точной длины данных.
- Ограничения памяти: 24 млн пикселей, 16 384 пикселя по стороне, 160 МБ на файл. Ошибка загрузки не удаляет открытый документ.

В ТЗ GB7 есть опечатка: после указания старшего бита маски дважды упоминается «бит 0». Здесь маска занимает **бит 7**, как указано в описании структуры пикселя; младшие 7 бит целиком отведены серому. При выключенном флаге маски старший бит должен быть нулём.

Серый при экспорте: `round((0.299 R + 0.587 G + 0.114 B) * 127 / 255)`. При чтении: `round(gray * 255 / 127)`. GB7 поддерживает только двоичную прозрачность: Alpha < 128 становится 0, Alpha >= 128 становится 255; наличие любого Alpha < 255 включает маску файла.

## Лабораторная 2

- Каналы Gray, Gray + Alpha, RGB, RGB + Alpha определяются метаданными формата, а не случайным содержимым изображения. PNG с палитрой разворачивается в RGB; tRNS добавляет Alpha. CMYK JPEG браузер преобразует в RGB, исходная глубина отмечена в статусе.
- Для каждого канала своя миниатюра интенсивности в оттенках серого и независимый флажок видимости.
- Выключенные цветовые компоненты обнуляются. Выключенный Alpha делает цвета непрозрачными. Только Alpha показывает непрозрачную серую маску: чёрный = прозрачный, белый = непрозрачный. Все выключенные каналы дают чёрное изображение.
- Пипетка считывает пиксель текущего вида canvas, без влияния шахматного фона и маркера. Координаты отсчитываются от нуля относительно изображения, включая режим вписывания и прокрутку. Показаны RGB 0–255, Alpha и CIELAB (sRGB, белая точка D65).
- Выбор через левую кнопку мыши; на сфокусированном canvas Enter выбирает центр, стрелки передвигают выбранную точку. Панель обновляется и при изменении каналов.
- Канальные преобразования выполняются порциями с передачей управления браузеру; устаревшие результаты быстрых переключений не отображаются.

## Лабораторная 3

- Инструмент «Уровни» работает через `dialog`. Настройки Master, Red, Green, Blue и Alpha сохраняются отдельно в пределах сеанса коррекции. Master действует только на цветовые компоненты, Alpha доступна у изображений с прозрачностью.
- Гистограммы рассчитываются из исходного снимка документа; композитная гистограмма использует светлоту `0.299 R + 0.587 G + 0.114 B`. Есть линейная и логарифмическая шкалы. Для исходного GB7 шкала 0–127, для остальных документов 0–255.
- Маркеры чёрного, гаммы и белого связаны с числовыми полями. Крайние маркеры не пересекаются, гамма остаётся между ними. Диапазон гаммы 0.1–9.9; преобразование использует степень `1 / gamma`.
- Предпросмотр включён при открытии. Отключение флажка возвращает снимок до коррекции; отмена и Escape закрывают окно без изменения документа; сброс возвращает исходные параметры всех каналов; применение сохраняет результат.
- После коррекции документ хранится как 8-битный растр на компонент. Раздельное изменение цветовых компонентов серого изображения переводит его в RGB.

## Лабораторная 4

- Собственные алгоритмы ближайшего соседа и билинейной интерполяции находятся в `src/domain/resample.js`. Билинейная интерполяция используется по умолчанию, прозрачность интерполируется с учётом предварительного умножения цвета на Alpha.
- Масштаб просмотра 12–300% задаётся в строке состояния. При загрузке рассчитывается вписывание с отступами 50 px, насколько это допускает минимальный масштаб 12%. Видимая область пересчитывается собственным алгоритмом; при прокрутке большой картинки не создаётся буфер всего увеличенного изображения.
- Диалог размера показывает число пикселей до и после, поддерживает пиксели и проценты, связь пропорций, выбор метода и подсказку к нему. При применении сохраняется выбранный масштаб просмотра.
- Размеры проверяются на положительность, целочисленность пикселей и ограничения памяти, описанные выше.
- Проценты рассчитываются от размеров документа на момент открытия диалога. Переключение единиц сохраняет выбранный размер в пикселях.

## Лабораторная 5

- Диалог «Фильтры»: закрытие, отмена, сброс, применение, флажок предпросмотра и редактируемая сетка 3×3. Поля принимают десятичные числа, в том числе с запятой, и дроби вида `1/9`. Коэффициенты ограничены диапазоном ±1 000 000; деление на ноль и неконечные значения запрещены.
- Пресеты: тождественное отображение, повышение резкости, Гаусс 3×3, прямоугольное размытие, Прюитт X и Y. Изменение поля переводит выбор в «Своё ядро».
- Флажки независимы от видимости каналов в основной панели. Для серого изображения доступен Gray, для цветного R/G/B; Alpha доступна при наличии прозрачности. По умолчанию выбраны цветовые каналы, Alpha сохраняется без изменений.
- До свёртки каждый выбранный канал расширяется на один пиксель с каждой стороны. Край заполняется 0, 255 или копией ближайшего крайнего пикселя, включая углы. Размер результата совпадает с размером исходного документа.
- Используется математическая свёртка: `out(x,y) = sum K(dx,dy) * source(x-dx,y-dy)`. Ядро разворачивается на 180°, что важно для несимметричных коэффициентов. Результат округляется и ограничивается диапазоном 0–255; модуль, сдвиг и автоматическая нормализация не применяются. Нормирующие множители уже включены в пресеты размытия.
- Предпросмотр и применение используют снимок текущего документа на момент открытия окна, включая ранее применённые уровни или изменение размера. Предпросмотр обрабатывает полное разрешение и не накапливает эффект при изменении настроек.
- Отключение предпросмотра, отмена и Escape восстанавливают состояние до открытия окна. Сброс возвращает тождественное ядро, цветовые каналы, копирование края и включённый предпросмотр, оставляя окно открытым.
- Расчёт выполняется асинхронными порциями с прогрессом. Устаревшие расчёты отменяются при изменении настроек; кнопку отмены можно нажать и во время применения большого фильтра до сохранения результата в документ.

## Структура

- `src/domain/`: пиксельные операции, цветовые пространства, каналы и собственная тестовая мишень.
- `src/io/`: GB7, метаданные PNG/JPEG, браузерное чтение и экспорт.
- `src/ui/`: стили и подключение значков.
- `src/main.js`: состояние документа и события интерфейса.
- `vendor/lucide/`: выбранные значки Lucide и лицензия.
